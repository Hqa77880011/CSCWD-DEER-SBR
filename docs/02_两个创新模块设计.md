# DEER / SBR：无教师证据路由与观测支撑的有界残差

> 2026-10-19，当前协议 `teacher_free_v4`（schema4）。DEER/SBR 沿用 v3 结构和损失，本轮修复评测 BN 统计策略；检查证据、资源和命令见 [08](08_实现验收与训练资源配置.md)。正式 AP 尚未运行。评分仍为 `project_fix_v1`，它与训练协议版本是两个独立字段。
>
> v2 最小可复现基线见 [v2 归档](../setup/teacher_free_v2_archive/README.md)，v3 原实现、配置和验收见 [v3 归档](../setup/teacher_free_v3_archive/README.md)。v4 正式比较必须重新初始化，不能恢复 v2/v3 诊断 checkpoint 或合并旧结果。旧教师方案保存在 [历史归档](../setup/teacher_v1_archive/)。

## 1. 方法目标与贡献边界

DEER 分别预测缺失与伪回波辅助分数，以可信类型标签训练，并控制双模态融合。SBR 从有限物理邻域的真实 Radar 观测取得供体，以有界、任务驱动的残差修正局部表示。两者均在每个 agent 本地工作，之后沿用原 AttBEVBackbone 内的 AttFusion，不额外叠加协同网络。

普通门控、局部注意、残差、空候选、tanh 和 Radar 旁路本身都不是首创。L4DR、MDD、HRCP、RAF 的已有机制和来源见 [07](07_参考文献与证据索引.md)。待验证的是：类型解耦、保留分支信息的路由、真实支持和修正边界的组合是否有检测价值。未承诺任何提分幅度。

v3阶段审查 v2 的具体失效机制并实现以下两个候选改动；当前v4保留这些结构，只修订第7节的BN统计策略：

| 可检验假设 | v3 实现 | 对照及限制 |
|---|---|---|
| 每 agent/channel RMS 归一化使控制路径对整模态正比例缩放近似不变，可能遗漏有用能量信息 | 保留归一化空间输入，补充当前 occupied RMS 的低维 `log1p` 描述，经无 bias 的 2C→hidden 投影后广播相加 | N1 用同层、同初始化、同参数数目的归一化 occupied mean 描述，控制增加活跃容量；幅度也可能是无用噪声，正式验证待做 |
| null 注意力和类型幅度乘子共同缩小真实供体路径，类型已经进入残差网络，额外固定乘法可能妨碍检测 | 取消 B 的显式类型幅度乘子，detach 类型仍作为输入，由检测学习使用程度 | N2 恢复 v2 乘子，其他设置完全相同；本轮不扩大半径、rho、隐藏层或改损失 |

v2 的 route head 与显式类型偏置可能互相抵消，现增加通用 logit / 类型偏置 / 合成 logit 分解诊断。将类型偏置改成零中心并同步平移可学习 bias 与旧 softmax 数学等价，故不把这种重参数化算改进，也没有增加第三套门控。两模态的最低增益仍为0.5。类型头隔离不意味着共享 encoder/VFE 没有辅助梯度冲突；本轮测量检测与辅助梯度范数和夹角，不能由短测宣称冲突已解决。

这些是设计依据。训练分区诊断只检查路径是否可学习，不能替代正式 AP 比较。

## 2. 共享底座和数据边界

插入点为双 PillarVFE / Scatter 后、AttBEVBackbone 前。输入 `F_L,F_R` 为 `[sum_agents,C,H,W]`，当前 V2X-R 为 C=64、网格 0.4m。共享路径：

\[
Z_0=\Phi_{base}([F_L,F_R]),\quad
F_{local}=\Phi_{out}([Z,F_R]).
\]

`Phi_base` 无 bias、128→64，初始化 `[I,0]`；`Phi_out` 无 bias、128→128，初始化为 I。S0/A/B/AB 均有这些投影和原始 Radar 旁路，两模态均标为可用时初始输出相同。投影随后可学习；不能把 S0 当官方 L4DR。协同 backbone 和检测头保持原有接口。

`proj_first=true`，loader 将各 agent 投影到同一 ego 网格，模块内不再 warp。观察图为真实测量经过几何、FOV 和范围筛选后的点数、占据、有效视场、距离与整帧模态可用性；padding、复制另一模态点、随机补点均不产生支持。距离以各 agent 实际传感器原点计算。

模型输入采用白名单。GT、类型目标、正常参考点、PCD 绿色天气标志、来源 ID 不进入推理。整帧空模态保留 agent、样本及固定 GT，不能跳帧或删 GT。真实扰动注入是已登记的训练观测增强，不是空云技术 padding。

## 3. DEER：类型监督与保留信息的路由

### 3.1 类型任务没有随教师删除

两个独立 sigmoid 输出 `d_miss,d_spur`，允许同时高。类型头只由有效区域的两项 BCE 训练。类型输出在进入路由偏置、B 输入及 B 先验前 `detach`；共享表示和点云编码器仍接收检测与辅助梯度。

无教师不等于无正常/天气配对。可信正常参考点可作为训练标签的构造依据，且不经过额外网络。当前支持：

- `none`：C 线正常占据网格的零类型负例；不能证明两类正例区分能力。
- `provenance_v1`：W 线正常时隙以固定概率做保留来源 ID 的删点/注入；精确记录哪些参考点删除、哪些观测点注入。仅 train，所有 S0/A/B/AB/SUP 使用相同扰动。
- `mutual_nn_v1`：正常/天气点数组的相互近邻配对，模糊部分屏蔽。未匹配点只有在外部来源语义审计通过后才能成为正例。该路径无需正常特征网络，也不生成教师体素输入。

`provenance_v1` 初值：probability=0.5，drop_fraction=0.2，inject_fraction=0.05，max_offset_m=0.3。删点为 Bernoulli 事件，比例为期望值；注入数量为 `ceil(N*inject_fraction)` 候选再经过几何筛选，最终比例逐帧记录。只施加于 W 的正常时隙，原天气调度仍按每 agent 4/7 Normal、3/7 Fog。注入为受控几何伪回波，不宣称物理雾/雪模拟或真实自然退化。Fog 来源语义未核验时仍全部屏蔽；没有用点数差或天气颜色替代真标签。

在相同几何变换及网格上：

\[
y_{miss}=N_{removed}/\max(N_{reference},1),\quad
 y_{spur}=N_{injected}/\max(N_{observed},1).
\]

分子来自显式来源事件，不由前后总点数相减。原本没有正常观测的网格不强行给缺失标签；空观测的伪回波比例不强行定义。各自保存有效掩码，未知值不参与损失。`normal_mask` 只标记未受扰动的正常时隙，不能对已扰动样本施加“应当不修改”的恒等标签。

### 3.2 尺度与路由

控制编码器读取 `F_L/s_L,F_R/s_R` 及当前观察图。`s_L,s_R` 按各 agent、各通道、真实占据单元计算 detached RMS；只归一化控制分支，原始检测特征及 Radar 旁路保持其可学习表示。

\[
\ell_L=h_L(E)-\beta_s\,sg(d_{spur}),\quad
\ell_R=h_R(E)+\beta_g\,sg(d_{miss}),\quad a=softmax(\ell).
\]

\[
g_m=1+\alpha(2a_m-1),\qquad Z_A=\Phi_{base}([g_LF_L,g_RF_R]),\quad\alpha=0.5.
\]

可用分支增益为 [0.5,1.5]，类型证据再强也不能完全擦除有效特征。不可用模态的分支和增益严格为零；两模态均不可用时不计算全 `-inf` softmax。单个空网格不等于整帧传感器不可用。

v3 的控制投影变为

\[
E=Encoder(\Phi_{ctrl}([F_L/s_L,F_R/s_R,O])+W_{amp}[\log(1+s_L),\log(1+s_R)]).
\]

尺度及描述均 detach，只读当前真实观测；`W_amp` 为无 bias 的128→16投影，在1×1描述上计算后广播，新增2,048参数，不构造128通道稠密描述图。归一化前的检测分支与 Radar 旁路保持原始单位。N1 描述为 occupied `mean(F)/s`，仍是随输入变化且可训练的容量控制，对未触发尺度guard的正比例缩放不变；它不是删掉分支的死参数对照。尺度 guard 触发时不能要求精确缩放不变。

类型末层权重/偏置为零，路由末层权重为零，偏置抵消初始类型得分，因此两模态均可用时初始 `a_L=a_R=.5,g_L=g_R=1`；单模态故障时可用分支权重为1、增益1.5，不能宣称故障路径也与S0初始相等。M2 按 1/3 类型初值补偿。新增幅度层在旧层之后初始化，optional 分支使用隔离 RNG；同seed的共享检测参数与v2不变。该保留增益不是已验证最优选择，后续以 Normal/Fog validation 检验。

## 4. SBR：真实支撑、尺度匹配与有界修正

### 4.1 有限物理邻域

在当前网格上枚举中心距离不超过 0.8m 的候选；0.4m 网格对应 5×5 包围框内的 13 个圆盘位置。候选必须有真实 Radar 点、有效视场且整帧 Radar 可用。额外保留特征为零、始终有效的空候选。只有卷积激活不能成为观测支撑。无真实候选时 donor=0、null 权重=1。

该范围不会自动扩展到整个目标或其他 agent。Astyx 需要按实际网格重新计算物理范围并完成 adapter 检查，目前未实现其端到端验证。更宽范围既可能改善稀疏供体覆盖，也可能传播杂波或错位误差。

### 4.2 当前学生尺度取代冻结校准

对 `Z` 在当前 LiDAR/Radar 真实占据并集、各自有效区域上计算各 agent/channel RMS：

\[
e_{ic}=\frac{\sum_b O_i(b)\,sg(Z_{ic}(b))^2}{\max(\sum_b O_i(b),1)},\quad
s_i^{raw}=\sqrt{mean_c(e_{ic})},\quad \bar s_i=clip(s_i^{raw},.001,1000),\quad s_{ic}=clip(\sqrt{e_{ic}},.1\bar s_i,10\bar s_i).
\]

实现再以 [1e−3,1e3] 做数值 guard；空占据使用正下界，不制造观测支持。尺度没有可训练参数、运行均值、checkpoint 校准标志或额外校准 pass；train/eval 使用同一单帧规则。若 agent 的当前 Z 未guard的整体真实占据 RMS ≤ 数值下界、但存在真实 Radar 观测，则回退使用该 Radar 的当前 occupied RMS，防止 LiDAR 整帧缺失且初始 Z=0 时把 Radar 修正限在近零；没有 Radar 时仍只有数值 floor 和零支撑。它会随当前学生和当前输入变化，**不是旧教师正常特征的固定物理标尺**，不能称为概率校准或全模型稳定性的保证。

Radar 供体按自身真实 Radar 占据 RMS 归一化，query/key 在归一化域打分；聚合后以学生尺度解释。残差控制输入同样采用归一化 `Z` 和 Radar。原始 Radar 检测旁路保留。q/k 使用单位球投影（零点 eps=1），真实候选打分在 [−2,2]；null logit 加 `log(候选数)`，避免候选数量本身压低拒绝概率。全部真实打分为零时，存在候选的初始 null 质量为0.5，无候选为1。

### 4.3 修正边界

v3 的 `type_prior_mode=input_only`：类型分数停止梯度后仅进入残差控制输入，不再额外乘固定幅度先验。A 关闭或 M6/SUP 时类型输入为零、has_A=0；B 独立工作，不读取 A 缓存。

\[
\Delta=S_R\rho s\tanh(f_B(Z/s,D/s,sg(d_{miss}),sg(d_{spur}),O)),\quad Z_B=Z+\Delta,\quad\rho=.25.
\]

N2 恢复 v2 的 `G_A=.25+.75 max(sg(d_miss),sg(d_spur))` 并乘在残差上，初始0.625；无 A 时为1。主 v3 不再有这个乘子。null 仍用于拒绝供体，硬支持和 tanh 边界继续保留。

标准 B 无支持时严格零修正，逐通道 `|delta|≤rho*s`。该边界只约束新增残差，无法约束整个检测器误检。末层零初始化使初始恒等；初始化时最后一层有检测梯度，更新后上游残差/供体路径才逐步获得梯度。不能要求零初始化第一步所有 B 参数都有非零梯度，也不能因此直接判定模块失效。

## 5. 无教师损失

\[
L=L_{det}+w(t)[.1L_{type}+.001L_{size}+.01L_{id}],
\]

\[
L_{type}=mean_{U_{miss}}BCE+mean_{U_{spur}}BCE,\quad
L_{size}=mean_{S_R}(\Delta/sg(s))^2,\quad
L_{id}=mean_{normal\_mask\cdot S_R}|\Delta/sg(s)|.
\]

`L_det` 沿用固定检测任务，忽略 anchor 不作为负例。当前入口 `w(t)=1`，没有另设辅助 warmup；若后续改调度，须同时修改所有匹配对照并登记。size 弱惩罚没有方向偏好，由检测损失学习修正方向；恒等约束只作用于真实正常时隙。两者在实际支持区域归一化，避免稀疏网格稀释。零残差处平方/L1 的实现梯度为零，不阻断初始化时检测梯度。

**已删除**正常教师、正常特征拟合 `L_repair`、教师 checkpoint 加载、额外正常体素前向、冻结 RMS 工件及其校准 CLI。传入旧教师特征或损失参数会明确拒绝。弱正则仍可能把无效 B 收缩至零；真实小样本非零残差只证明路径能学习，不证明 AP 有收益。

## 6. 比较与验证

四组、SUP、M1–M6 与 N1/N2 的当前定义见 [04](04_训练对比与消融实验.md)。SUP 获得同一训练观测、可信类型标签、辅助权重、动态尺度规则和预算，使用普通门控/普通残差且类型输出不进入控制路径。它不采用硬输出支撑和 tanh 边界，但幅度/正常约束仍按共同观察掩码计算，避免改变监督覆盖；SUP/M3 在无支持区域产生的自由残差只受检测任务约束，须在消融中检查误检。

机制证据至少包括：可信标签覆盖与正例数量、按距离的正常稀疏错误率、route gains、support/null、归一化残差、触界率、检测与辅助梯度、正常误检以及 Radar 破坏表现。四格或 SUP 失败也必须保留。无教师节省的计算应在相同训练协议预算中体现，不能悄悄给 AB 更多更新再和 S0 比。

工程实现另消去 A 对已 mask 特征的重复整图 mask、B 的供体尺度乘除往返，并将幅度/恒等正则先按支持域选出小张量再计算。数学目标、支持分母与正常掩码不变；空支持仍保留可反向的零。相关输出/梯度等价检查及内存快照见08。轻分支 activation checkpoint 继续开启，不重算含BN的主干，不每步清理缓存。

已实现、已检查、待实验三种状态分别记录在 08。下一步最小正式对照仅在 Normal/Fog validation 上开展，冻结之后才允许 Snow test；本轮不启动。

## 7. v4：将在线 BN 状态与评测统计分开

v2/v3 短训权重的运行统计滞后会沿 VFE、backbone 和检测头逐级放大。24 个 BN 的调用次数、affine 和 EMA 更新公式均核对正确；轻分支重计算不包含 BN。PFN 的 singleton guard 改为检查 `self.norm.training`，使仅 BN 进入统计更新态时也走正确边界；这项边界修正不能解释普通样本中的百万量级损失。

v4 在线训练仍使用 FP32、BN eps=.001、momentum=.01、micro4/accum2。每 epoch 评测前固定参数，从 train 全范围按均匀中点取固定32帧，epoch0、无几何增强，C使用Normal、W沿用同seed的原Normal/Fog及来源扰动流。只把 BN 临时切到统计更新态，reset buffers 后用8个micro做PyTorch累计平均；其余模块保持eval，零梯度、零优化器更新。这里平均的是各micro的均值及无偏的micro内部方差，不是全局合并方差。

统计完成后全部模块设为eval，Normal/Fog及随后最终测试共用同一份冻结统计。推理不读GT、不更新统计、不按天气或当前batch另行拟合。当前学生RMS尺度规则不变，它与BN重估是不同机制。校准前向只使用推理输入白名单；GT仅用于诊断损失。

`latest.rank0.pt`保留在线BN、优化器和RNG，用于精确恢复；`selected.pt`在重估context内保存冻结统计和来源/策略/hash清单，仅用于推理。退出context恢复原buffers、模式、momentum和全部RNG；selected明确禁止继续训练。全部四格、SUP和消融共同登记这一额外计算（每epoch8次前向），不把它算作DEER/SBR结构收益。更快在线EMA和在线累计平均的负面结果、真正eval预处理检查及剩余假设见08。
